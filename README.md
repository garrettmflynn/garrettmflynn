# Garrett Flynn
Lead engineer at [Universal Brain](https://universal-brain.com), living in Los Angeles. I build open, standards-based software for brain data.

## Open source
- [Commoners](https://github.com/neuralinterfaces/commoners): one web app, shipped to desktop and mobile
- [NWB GUIDE](https://github.com/NeurodataWithoutBorders/nwb-guide): a desktop app for converting neurophysiology data to NWB

Previously, I founded the [Brains@Play](https://github.com/brainsatplay/brainsatplay) Initiative at USC and built tools with CatalystNeuro, Enosis, and the Human Technology Interaction Lab.
